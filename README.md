# Portfólio – Júlia Brasileiro Viana

Portfólio pessoal feito com HTML, CSS e JavaScript puros.

## Como publicar no GitHub Pages
1. Crie um repositório chamado `jbrasileiro007.github.io` (ou qualquer nome).
2. Envie `index.html`, `style.css` e `script.js` para a raiz do repositório.
3. Em **Settings → Pages**, escolha **Deploy from a branch**, branch `main`, pasta `/ (root)`.
4. Aguarde 1 a 2 minutos e acesse `https://jbrasileiro007.github.io`.
